# BRIGHTER data notes (M1)

Generated by `scripts/make_data_notes.py`. Counts only; no BRIGHTER text.

## Source

Source of truth: the SemEval repository, `data/raw/brighter/semeval_repo/task-dataset/semeval-2025-task11-dataset/track_{a,b,c}/{train,dev,test}/<lang>.csv`.
Columns: `id, text`, then one integer column per emotion the language has. Track B holds intensities 0 to 3.
No official evaluation script is in the data repository. The scorer lives in the separate repository `SemEval2025-Task11-Evaluation`: sklearn macro-F1 for Tracks A and C, per-emotion Pearson r for Track B. `emoldgn/evaluate.py` reproduces it (see `tests/test_metrics.py`).
Per-annotator files for optional N3 are in `semeval_repo/individual_labels/<lang>/` (12 languages: afr, arq, chn, deu, eng, esp, hin, mar, ptbr, ron, swe, ukr). The format varies by language; inspect it in M11.

## Findings that changed the pipeline

1. **English Track A test labels are blank.** Filled from SemEval Track C, whose labels equal Track A test for every other language and which matches all 2,765 English rows by text. Two texts duplicated in Track C with conflicting labels (6 rows) fall back to row-aligned Track B intensity > 0. Binarised Track B disagrees with Track C on 3 of 2,765 rows, so the choice barely matters.
2. **Hugging Face was not needed and is not safe to join for English test.** Its `eng` test split has 5,528 rows (2,762 distinct) and only 188 texts match SemEval exactly. It was still downloaded, as CLAUDE.md section 3 asks.
3. **`track_a/train/ron_track1_test.csv` is a stray file** (other schema, id prefix `ron_test_track1`, 116 texts shared with Romanian test). It is ignored; ingesting it would put test texts into training.
4. **Intensities join on text, not id.** After prefix normalisation, Track A and B ids point at different texts for amh and rus (0 agree) and for part of English train (2,071 of 2,763 agree).
5. **Track B's amh and rus splits differ from Track A's.** About 1,040 amh Track A train texts are in Track B test, and 178 rus Track A test texts are in Track B dev. Each row therefore keeps its Track A split, and Track B is scored on the Track A test part. Scoring official Track B amh/rus test would measure training data. Every Track B row has a Track A row, so nothing is lost; amh and rus Track B test row counts differ from the official files.
6. **Track C files repeat Track A test under new ids** for the 28 Track A languages. Only ind, jav, xho and zul have no training data, so only these are ingested as Track C and scored as zero-shot.
7. **Exact-duplicate texts cross official splits** in a few languages (test texts also in train or dev: ibo 72, swa 8, orm 6, tir 4, and 1 each in eng, esp, ptbr, swe). Official splits are kept as released.
8. **afr has no surprise column** (the README notes only that some languages lack an emotion); English has no disgust. Masks come from each file's header.
9. **The README's Track B Sundanese is absent** from the files: Track B has 11 languages (amh, arq, chn, deu, eng, esp, hau, ptbr, ron, rus, ukr), as in the task paper. Romanian has Track B dev and test only.
